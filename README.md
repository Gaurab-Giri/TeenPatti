# Teen Patti AI Lab

An AI-powered Teen Patti simulator exploring probability, game theory, opponent modeling, and reinforcement learning.

## About

A Python-based research project inspired by Nepali Teen Patti. The goal is to study player behavior, hidden information, and AI strategies through virtual-chip simulations.

## Current Features

- Standard 52-card deck
- Teen Patti hand evaluation and comparison
- Monte Carlo probability simulations
- Interactive Streamlit interface
- Virtual bankroll configuration

## Installation

Install dependencies:

    python3 -m pip install -r requirements.txt

Launch the application:

    python3 -m streamlit run app.py

## Disclaimer

Educational research and virtual-chip simulation only. No real-money gambling functionality.
